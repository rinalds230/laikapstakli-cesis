# Laikapstākļi Cēsīs

Laika prognozes lietotne Cēsīm un citām Latvijas pilsētām.

**Demo:** https://rinalds230.github.io/laikapstakli-cesis/

## Iespējas
- Tagadējie laikapstākļi: temperatūra, sajūtu temperatūra, vējš, mitrums, saullēkts un saulriets
- Prognoze nākamajām 24 stundām un 7 dienām
- Ātrā izvēle: Cēsis, Rīga, Valmiera, Sigulda, Liepāja, Daugavpils
- Jebkuras Latvijas pilsētas meklēšana
- Lietotne atceras pēdējo izvēlēto pilsētu (localStorage)
- Gaišais un tumšais režīms, pielāgojas telefonam

## Tehnoloģijas
HTML, CSS (Grid, Flexbox), JavaScript (Fetch API, async/await), [Open-Meteo API](https://open-meteo.com/)

## Palaišana
Atver `index.html` pārlūkā. API atslēga nav vajadzīga.
